TRINETRA HQ v1.0 — Android फोनवर वापरण्यासाठी

ही पहिली आवृत्ती installable PWA आहे. ती थेट APK नाही.

महत्त्वाचे:
- Lore नोंदी या Browser मधील IndexedDB मध्ये स्थानिकरित्या साठतात.
- नियमित Export Backup करा.
- Browser data clear केल्यास नोंदी जाऊ शकतात.
- AI Integration या आवृत्तीत नाही.
- Google Fonts इंटरनेट उपलब्ध असल्यास वापरले जातात; मुख्य अॅपची रचना स्थानिक फाइल्समधून चालते.

फोनवर वापरण्याची सोपी पद्धत:
1. ZIP extract करा.
2. या फाइल्स एका static hosting सेवेत upload करा (उदा. GitHub Pages).
3. मिळालेला HTTPS link Android Chrome मध्ये उघडा.
4. Chrome menu मधून "Install app" किंवा "Add to Home screen" निवडा.

फक्त फोन असल्यामुळे पहिल्या deployment साठी GitHub Pages किंवा दुसरी static hosting सेवा वापरता येईल.
पुढील टप्प्यात आपण सुरक्षित AI backend आणि Native Android packaging करू.
